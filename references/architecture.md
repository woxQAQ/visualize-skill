# 架构图

[公共接口](api.md) · [时序图](sequence.md)

`architecture(options)` 创建架构图。

| 字段          | 必填 | 内容                            |
| ------------- | ---- | ------------------------------- |
| `id`、`title` | 是   | 图表标识和非空标题              |
| `nodes`       | 是   | 非空节点数组                    |
| `relations`   | 是   | 有向关系数组，没有关系时传 `[]` |
| `partitions`  | 否   | 组件分区数组，默认 `[]`         |

## 节点与关系

每个节点包含 `entity`、`role`、`position`、`size`，以及可选的 `partition`。其中 `entity`、`role` 接收完整对象定义，不能只传标识字符串；通常复用 `entity()`、`role()` 的返回值。

每条关系包含 `id`、`from`、`to`、`label`，以及可选的 `variant`、`fromSide` 和 `toSide`，详见[关系样式](api.md#关系样式)和[关系连接边](api.md#关系连接边)。端点可以传对象或标识字符串，但两端都必须出现在当前图的 `nodes` 中。允许循环、自依赖和端点相同的多条关系，各条关系仍需独立标识。

节点只在上、下、左、右四条边的中点连接关系。`fromSide`、`toSide` 可以分别指定起点和终点的边；未指定的一端由系统根据避障和标签空间选择，多条关系可以共用同一个中点；不会按关系数量或顺序沿边分散端点。自依赖连接同一节点的两个不同侧中点。

路由优先减少不同关系的重叠长度，再减少交叉和绕行。共享连接点附近的引线也计入重叠代价，避免进入节点的箭头与离开节点的线合并。引线默认长 18 像素；相对障碍较近时缩短到间距的一半，仍须满足节点避障间距。系统同时比较多个沿线标签位置和最多 3 行的换行方案；不会通过减小字号或额外拆断完整英文词来压缩标签。关系声明顺序不决定通道分配，输出仍保留声明顺序。这是有限候选和有限重排下的优化，不保证任意密集图都没有重叠或交叉。

关系文字及其背景避开分区边框，连线仍可跨越边框。边框只限制标签放置，不会把分区内部视为不可穿越的障碍。

## 组件分区

`ArchitecturePartition` 表示架构组件分区，为一组组件划定布局区域。`architecture()` 用 `partitions` 声明分区，架构节点用 `partition` 指定归属；分区的位置和尺寸由作者通过 `position`、`size` 显式声明。

分区表示按明确标准划定的组件分组。分组标准由架构图要表达的内容决定：可以按职责聚合功能相近的组件，也可以按部署位置聚合同一区域中的组件。名称应让读者知道这些组件为什么放在一起，例如“订单处理”或“部署区域：华东”。分区标识只在所属架构图中有效，不能重复。

每个分区只有 `id`、`label`、`position`、`size`。分区名称是最多 48 个字符的单行短文本。节点的 `partition` 填所属分区的 `id`。分区不进入共享对象表，没有角色、标签或详情，不能作为连线端点；每个分区至少包含一个节点，当前不支持嵌套。

## 坐标与尺寸

`position` 为 `{ x, y }`，值必须是非负有限数字；`size` 为 `{ width, height }`，值必须是正有限数字。当前输出一单位对应一个 CSS 像素。

根节点和分区相对于画布内容原点定位。分区内节点相对于分区内容区定位；不要再次把分区自身的偏移加到节点坐标上。画布边距为 32，分区内容左右及底部留白为 24，内容顶部位于“分区标题高度加 24”之后再留 24。

主要依赖链先按阅读方向确定行或列的中心线。上下直连时令画布坐标下的 `x + width / 2` 相等，左右直连时令 `y + height / 2` 相等；不同宽高的节点不能只对齐左边缘或上边缘。跨分区时先计入分区位置、标题高度与内容内边距，再比较中心；相同的局部 `position` 不代表相同的画布位置。分支、回退或避障需要的转折可以保留。

中心对齐还需要配合标签空间。同排节点跨越分区边框时，系统按边框两侧各自的可用宽度尝试换行，最多 3 行；不会把两侧空白相加，也不会缩小字号或拆断能完整显示的英文词。标签背景与边框保留 2 像素间距。换行后仍放不下时，再缩短标签或调整节点与分区的位置。垂直主链可以从分区标题旁经过，路径与标题文本范围保留 8 像素间距；标题实际挡住路径时才需要绕行。

`compile()` 的几何严格采用声明尺寸；下述坐标规则描述缩放前的布局。节点左右各留 16 的文字空间，名称和摘要整体居中。同一层级节点、不同分区、分区与根节点之间至少留 12 的间距；实际连线可能需要更多空间。路由避开节点和分区标题，可以穿过分区边界。无法放置文字或连线时返回诊断，不自动扩容、移动或截断内容。

## 容量

每张图最多 12 个节点、16 条关系。节点名称最多排 3 行，摘要最多排 4 行，均须放入声明尺寸。画布最大宽 1280、高 2600。渲染时保留节点、分区和连线的原始布局，随容器宽度等比例缩小，文字一同缩放，详见[容器宽度](api.md#容器宽度)。
