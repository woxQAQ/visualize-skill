# Codex 对话内展示

## 1. 生成片段

使用 SDK 生成继承 Codex 主题的嵌入片段，保存到当前任务提供的 visualization 目录。

## 2. 检查展示

确认产物是嵌入片段，不包含完整页面外壳。按 [SKILL.md 的图像复核与修正流程](../SKILL.md#4-布局警告与图像复核)，在实际展示宽度下渲染并查看截图，完成连线与中心对齐复查；同时检查主题、窄容器和悬停强调，根据结果修正图表。若需要独立页面承载预览，可临时包装片段，但交付文件仍须是嵌入片段。引用文件必须与最后一次图像复核的版本一致。

## 3. 在回复中展示

在生成文件的同一轮最终回复中，为每张图输出一个原生可视化内容引用，独占一行，不加代码围栏。引用格式为 visualize{"path":"文件绝对路径"}，将其中的路径替换为实际生成文件的绝对路径。

背景和结论写在正常回复中。保存文件、提供文件链接或打开浏览器预览，都不能代替内容引用。
