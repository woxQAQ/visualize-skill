# 报告 Markdown

[公共接口](api.md)

`.markdown(source)` 接收非空字符串，使用项目内的解析器。这里定义的是报告所需的 Markdown 子集，不承诺完整 CommonMark 兼容。

| 内容 | 支持的写法 |
| --- | --- |
| 标题 | `#` 至 `######`；标题下方使用 `===` 或 `---` |
| 段落与换行 | 空行分段；行尾两个空格或反斜线表示显式换行 |
| 行内文字 | `*强调*`、`**加粗**`、嵌套强调、反引号代码 |
| 列表 | 无序、有序、嵌套和含多个段落的列表项；保留有序起始值 |
| 表格 | 竖线分列，表头后接分隔行；支持列对齐与行内格式 |
| 引用 | 每行带 `>`，引用内空行写为单独的 `>` |
| 代码块 | 反引号或波浪号围栏、四空格或制表符缩进；围栏可写语言名 |
| 链接 | 行内链接、引用式链接、尖括号包裹的 URL 或邮箱 |
| 其他 | 分隔线、反斜线转义 ASCII 标点、支持的字符引用 |

列表项的续行和子块使用空格缩进到正文列。模板字符串会先去除所有非空行的共同空格缩进。未闭合的围栏代码块延续到输入末尾。代码只作为转义文字输出，不执行，也不提供语法着色。

引用式链接的定义写在一行内，可以出现在使用位置之后。标签匹配忽略大小写并合并连续空白，第一次定义生效；代码块中的定义无效。未定义的引用按普通文字保留。

链接只接受 `http://`、`https://`、`mailto:`，以及以下内部引用：

- `[对象名称](entity:api)`：引用至少一张图中声明过的对象。
- `[图表名称](diagram:order-architecture)`：引用加入文档的图表。

内部引用可以指向后续图表。链接不能嵌套。原始 HTML、图片节点和不允许的链接地址会产生诊断；需要展示 HTML 代码时放入代码块。

字符引用支持十进制、十六进制数字，以及 `amp`、`lt`、`gt`、`quot`、`apos`、`nbsp` 六种名称。其他命名字符引用保留为文字。任务列表、删除线和脚注没有专门语义，按普通文字与已有块结构处理。

块结构与强调各最多嵌套 32 层。

## 表格

每行用 `|` 分列，首尾的 `|` 可省略。表头下一行用 `---` 分隔，每列至少三个连字符；`:---`、`:---:`、`---:` 分别表示左、中、右对齐。表头与分隔行的列数必须一致，否则按普通文字处理。

单元格支持强调、代码和链接，包括对象与图表引用。文字和代码中的竖线都写为 `\|`。表体少列补空，多列忽略多出的单元格；空行、不含分隔竖线的行或新的块结构结束表格。单元格不支持多行、合并或嵌套块。宽表可横向滚动。
